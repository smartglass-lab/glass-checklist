# グラスチェックリスト — Glass Checklist

Meta Ray-Ban Display 用の**持ち物・手順チェックリスト**。文字入力ができないメガネでもすぐ使えるように、**外出前・朝のルーティン・寝る前・旅行の持ち物・出張・キャンプ・ジム・雨の日・防災バッグの9種類のリスト（8〜15項目）**をはじめから収録。D-pad の↑↓で項目をえらんでタップするとチェックが気持ちよく入り、次の未チェック項目へ自動で進むので、玄関でタップを重ねていくだけで「鍵・財布・スマホ・火の元…」を確認できる。左の進捗リングで残りがひと目でわかり、ぜんぶチェックすると紙吹雪の完了演出。使わない項目は編集モードでかくして自分用に絞り込める。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-checklist.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / DOM / Canvas / 静的サイト）

## 特徴

- **すぐ使える9種のプリセット** — 🚪外出前（10）／🌅朝のルーティン（9）／🌙寝る前（8）／✈️旅行の持ち物（14）／💼出張（12）／⛺キャンプ（15）／🏋️ジム（8）／☔雨の日（9）／🎒防災バッグ（13）
- **タップでチェック → 次の項目へ自動で進む** — チェック円がはずんで緑のチェックマークが描かれ、行に光が走って取り消し線が引かれる。タップをくり返すだけで上から順に確認できる
- **進捗リング** — 「4/10・あと6こ」を左側にいつも表示。一覧画面でも各リストの進み具合をバーで表示
- **完了演出** — ぜんぶチェックすると紙吹雪と「ぜんぶOK！ いってらっしゃい！」（リストごとにひとこと）
- **使わない項目をかくす** — リスト末尾の「✎ 項目をかくす（編集）」で、項目ごとにタップで 表示／かくす を切り替え。「すべて表示にもどす」も。かくした項目は進捗に数えない
- **まとめてリセット** — 「↺ チェックをリセット」はタップ2回で実行（誤操作防止）
- **保存と「つづき」** — チェック状態・かくした項目・最後に使ったリストを localStorage に保存。タイトルの「▶ つづき」で前回のリストへすぐ戻れる

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ（「▶ つづき」「リスト一覧」「つかいかた」） |
| リスト一覧 | ↑↓←→でえらんでタップ（左上の「← もどる」でタイトルへ） |
| チェックリスト | ↑↓で項目をえらび、タップでチェック／チェックを外す。先頭の「← リスト一覧へ」、末尾の「↺ チェックをリセット」「✎ 項目をかくす（編集）」 |
| 編集モード | ↑↓でえらび、タップで 表示／かくす。先頭の「✓ 編集おわり」でもどる |
| 完了 | ↑↓でえらんでタップ（「リスト一覧へ」「← リストを見る」「↺ リセットしてもう一度」） |
| つかいかた | タップで「← もどる」 |
| PC確認用 | Escape でひとつ前の画面へ、行やカードのクリックでも操作可（グラスの戻るジェスチャーは使用不可のため補助のみ） |

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%83%81%E3%82%A7%E3%83%83%E3%82%AF%E3%83%AA%E3%82%B9%E3%83%88&appUrl=https%3A%2F%2Fglass-checklist.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスチェックリスト`、URL `https://glass-checklist.vercel.app` を入力。
